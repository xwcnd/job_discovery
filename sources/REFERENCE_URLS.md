# Platform setup references

Current product behavior and availability may change. Verify these official pages when installing the workflow.

- ChatGPT Projects: https://help.openai.com/en/articles/10169521-projects-in-chatgpt
- ChatGPT Scheduled tasks, limits and access rules: https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt
- Connected apps and permissions: https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt
- LinkedIn job alerts: https://www.linkedin.com/help/linkedin/answer/a511279/job-alerts-on-linkedin
- LinkedIn alert management: https://www.linkedin.com/help/linkedin/answer/a1420165
- Gmail search operators: https://support.google.com/mail/answer/7190
- Google Sheets import: https://support.google.com/docs/answer/40608
- GitHub email privacy and commit metadata: https://docs.github.com/en/account-and-profile/concepts/email-addresses
- GitHub history rewrite cautions: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository

Notes at the time of drafting (November 2026): LinkedIn's help documentation describes **daily or weekly** email alerts and a **20-alert maximum** per member. OpenAI's Scheduled tasks guidance specifically warns that tasks created in Projects cannot access uploaded files or files stored in the Project. Features and account limits vary. Do not copy a sample configuration and assume its connected apps are available to everyone.
