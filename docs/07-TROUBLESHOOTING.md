# Troubleshooting

| Symptom | Most likely diagnostic | Correct response |
|---|---|---|
| ChatGPT cannot open repository link | Repository private, unavailable, blocked or inaccessible to current tools | Attach the ZIP or documents; do not fabricate having read them |
| Project answers use only the short resume | Wrong source priority or missing full CV | Designate authoritative base CV and project list, verify direct readback |
| Scheduled task scores without reading CV | Project-uploaded sources inaccessible to scheduled tasks | Stop scoring; verify an independently connected private source before resuming |
| Task has no Gmail results | Wrong mail account/sender, label/archived filter, no alerts, access unavailable | Inspect a genuine received alert and connector state, adjust queries |
| Same role appears twice | Dedupe by title only or tracking-parameter URL differences | Compare employer requisition and LinkedIn job IDs; maintain one verified row |
| Score appears strong for wrong discipline | Generic terminology credited as direct domain work | Identify actual product/process, specialist depth and independence; fail functional gate if necessary |
| Required credential cited from search result but absent in user's screenshot | Search-indexed or third-party stale JD | Compare exact current employer page and full user evidence; retract stale requirement |
| User knows common software but marked missing | A broad suite name was mistaken for absent basic tools | Credit actual baseline; separately test specific advanced system/proficiency |
| Unfamiliar specialist tool called learnable | Ability to learn mistaken for past experience | Record gap and user choice to apply, but don't claim mandatory experience met |
| Rejected role remains in `Job Matches` | Score was cleared but entire row not reconciled | Re-run assessment; delete entire disqualified row, preserve audit; verify by stable IDs |
| Job page visible but Apply disabled | Reading a JD mistaken for confirmed open application | Record actual current apply-state uncertainty; do not claim submissions available |
| Spreadsheet writes shifted to wrong row | Historic row number reused after deletion | Search by stable job identity and read neighboring rows after edits |
| Automation silently disabled | Task paused, account limit, approval or app state changed | Check Scheduled live state, fix underlying issue with authorization, do not make duplicates |
| Run returns no matches but claims success | No visible summary or source-read counts | Require explicit zero/new/blocked statuses and verification links |

**Priority:** protect source truth and privacy first, repair the actual connected artifact second, update reusable instructions third. A changelog entry alone is not a live-system fix.
