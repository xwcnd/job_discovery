# Screening failure patterns and calibration cases

These examples are **synthetic**. They describe general error classes, not the work history of a real candidate.

## 1. Generic industry false positive

An applicant has personally led laboratory equipment qualification and production improvements in consumer electronics. The vacancy is a senior process specialist responsible for hazardous-fluid transfer systems in a regulated chemical plant. Keyword matching finds `R&D`, `quality`, `supplier`, `pilot line`, `process improvement` and predicts a strong match. **Error:** the core systems, hazards and independent technical judgments are materially different. **Fix:** inspect employer + hiring team + actual process + 2–4 defining duties; apply functional-domain gate before scoring. Do not invent a chemical-industry *mandatory* bullet if employer merely calls it preferred; functional credibility is a separate safeguard.

## 2. Specialized testing and reliability leadership

Applicant builds electronic test fixtures and automates data acquisition; vacancy requires leading validated lifetime-reliability testing of industrial sensor devices, including specific device failure physics, validated methods and uncertainty. **Error:** assuming any metrology/Python and generic leadership demonstrate that exact specialist maturity. **Fix:** distinguish using instruments, designing setups, automating, validating repeatability, owning domain-specific device methods, and leading that same specialist team. Score only with substantiated specialist scope.

## 3. System integration vs full design-and-tolerancing ownership

Applicant integrates standard factory-control modules; vacancy requires independent safety-critical control-system architecture, performance budgeting, verification and delivered-system ownership. **Error:** years in a related optics industry used as proof of a different specialty. **Fix:** separately evidence design, optimization, integration, testing, tolerances, delivery and examples at the required depth; do not equate total industry tenure with tenure in exact role-defining skills.

## 4. A mandatory certification invented from stale indexed text

Search result for an employer page appears to add a required certification missing from the full currently rendered JD and the candidate's screenshot. **Error:** treating stale search-indexed content as more authoritative than current exact evidence. **Fix:** reconcile the full same-job live JD, count and preserve its requirement bullets; do not create a gate absent from it.

## 5. A tool name is either over- or under-weighted

Applicant has normal office-suite experience; vacancy asks for Word/Excel/PowerPoint. **False negative:** marking each routine app absent because the CV names only the suite. By contrast, a vacancy requires SQL-based manufacturing ERP extraction or project scheduling software. **False positive:** assuming the office-suite entry proves these specialist tools. **Fix:** credit documented ordinary proficiency, identify the exact advanced behavior separately, and respect an applicant's explicit admissions of unfamiliarity.

## 6. "I can learn it" becomes prior experience

Candidate confirms no prior experience with a mandatory tool but wants to apply regardless. **Error:** converting learning willingness or access to AI tools into evidence they already used the required software. **Fix:** preserve `NOT MET`, support an honest discretionary application, keep outside verified-match tracker unless genuine new evidence/employer clarification changes the gate.

## 7. Disqualified job remains visible in a verified-only sheet

Assistant withdraws an 84% score but merely empties its G cell while leaving company/title in `Job Matches`. **Error:** the verified list still contains a role that no longer qualifies. **Fix:** delete the **entire** row, preserve the private reason in separate audit, search by stable ID, and read back zero verified occurrences. Don't blindly delete other mixed historical entries.

## 8. Job page mistakenly treated as open application

A company-hosted listing is viewable, but the application flow is disabled or status is unclear. **Error:** confidently reporting that applications are open. **Fix:** distinguish `JD accessible` from `employer accepting applications`; verify exact requisition/apply state. An old third-party closed flag is not conclusive without checking the live employer channel.

## 9. Automation runs on the wrong candidate version

A recurring task can read Gmail and a previous short CV, but not the user's current complete base CV stored only as a ChatGPT Project upload. **Error:** scoring from memory or an outdated derived summary while claiming full evidence review. **Fix:** independent scheduled-task source-access preflight, private connected primary documents, and fail-closed status if unavailable.

## 10. Duplicate write from multiple alerts

Same job arrives from an alert digest, notification and corporate careers page. **Error:** three rows or repeated expensive full re-screenings. **Fix:** dedupe message IDs separately from job IDs, retain stable ATS/LinkedIn identifiers, search live sheet and audit before writes, update existing qualifying row rather than append.

## 11. User feedback recorded but not implemented

A method rule is corrected in chat and GitHub, but the active scheduled task still uses the older prompt, and an invalid job remains in Sheets. **Error:** believing documentation changes update actual live systems. **Fix:** identify which systems are affected, update each **with permission**, read back actual task and sheet and record what could not be changed.

## 12. Applying too strict a domain ban

Applicant led industrial equipment procurement, acceptance and site commissioning; job is general project coordinator in a different manufacturing sector, with no requirement to design its proprietary product. **Error:** excluding solely because product industries differ. **Fix:** evaluate real defining work. Substantiated equivalent PM/supplier/QA experience may be sufficient when the vacancy is genuinely cross-domain. A company-sector gate must not become an invented employer qualification.

## 13. Over-specific salary or geography gate

Candidate's salary target or relocation preference is treated as if the employer required it, or a local work permit is mistakenly assumed to cover another country. **Fix:** keep employer constraints separate from candidate preferences, explicit country authorization and negotiable compensation. Do not annualize hourly postings as guaranteed annual compensation without actual hours.

## 14. Required evidence lost in tailored documents

A strong original project is removed during a summary rewrite because it sounds less fashionable, while generic adjectives replace facts. **Error:** whole-document quality regresses even though a paragraph sounds better. **Fix:** compare tailored CV against complete primary sources and exact JD, preserve direct evidence and roles, keep important projects visible and quantify only supported results.
